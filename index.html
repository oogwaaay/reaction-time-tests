Browser reaction-time tests

A short, practical list of free tests that run in the browser, no account needed.

  • ReflexTimer — reaction time with a 5-trial average, CPS, aim trainer, ruler drop, number memory and a spacebar clicker. Scores stay in localStorage.
  • Human Benchmark — the classic 5-trial reaction test.
  • TestReaction — reaction test with rating bands.

How to read the numbers

  • Compare the average of several trials, not one click.
  • The commonly cited adult visual reaction range is 200–250 ms.
  • Readings under ~150 ms on a web test usually mean anticipation or a very fast display, not superhuman reflexes.

Methodology: reflextimer.com/methodology. Average by age: reflextimer.com/average-reaction-time.
