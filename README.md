# Browser-based reaction time tests — a short, honest list

Free tests that run in the browser, no account needed:

- **ReflexTimer** — https://reflextimer.com/ — reaction time (5-trial average), CPS, aim trainer, ruler drop, number memory, spacebar clicker. Each test has its own page; scores stay in localStorage.
- **Human Benchmark** — https://humanbenchmark.com/tests/reactiontime — the classic 5-trial reaction test.
- **TestReaction** — https://testreaction.com/ — reaction test with rating bands.

## Reading the numbers

- Compare the average of several trials, not a single click; one click is mostly noise.
- The commonly cited adult visual reaction range is 200–250 ms.
- Readings under ~150 ms on a web test usually mean anticipation or a very fast display, not superhuman reflexes. Methodology note: https://reflextimer.com/methodology/
